# The picture that tastes of one ingredient

A top-down bowl of ramen — golden broth, wavy noodles, ajitama egg,
chashu, narutomaki, green onions and steam — drawn procedurally in pure
Python and served as a single PNG.

- `gen_image.py` renders `entry.png` (768x768, stdlib only: `struct` +
  `zlib`, hand-rolled PNG encoder, 2x supersampling, no PIL, no fonts).
- `main.py` is the entry program the grader runs: it copies the
  pre-rendered `entry.png` to `$MAKEFUN_OUTPUT_DIR/entry.png`
  (stdlib only, verified byte-for-byte).
